# Research Map

### Source 01 — Onion Skinning

**Creator:** Stop Motion Studio / Cateater

**Type:** Software documentation

**Link:** <https://help.stopmotionstudio.com/en/manual/Onion_Skinning>

**Why It Matters:** Explains how existing onion-skin tools allow animators to compare frames during capture. This provides a useful starting point for understanding what features already exist and how an AI assistant would need to offer something different.

### Source 02 — Dragonframe Software Features

**Creator:** Dragonframe

**Type:** Software overview / technical documentation

**Link:** <https://www.dragonframe.com/dragonframe-software/>

**Why It Matters:** Dragonframe includes professional animation tools such as overlays, difference mode, and image review. Studying these features could help establish what technical problems have already been addressed and where beginner-focused AI assistance might offer additional value.

### Source 03 — Visual Image Comparison

**Creator:** scikit-image contributors

**Type:** Technical documentation / coding example

**Link:** <https://scikit-image.org/docs/stable/auto_examples/applications/plot_image_comparison.html>

**Why It Matters:** Demonstrates techniques for visually comparing two images, including difference and blended views. These methods could be useful as a technical starting point or baseline when testing AI-assisted frame comparison.

### **Source 05 — How to Reduce Flicker? What Are Possible Sources of Flicker?**

**Creator:** Dragonframe / DZED Systems

### **Source 07 — Make a Stop-Motion Animation**

**Creator:** ACMI (Australian Centre for the Moving Image)

**Type:** Educational guide / Production tutorial

**Link:** [https://www.acmi.net.au/education/school-program-and-resources/make-stop-motion-animation/](https://www.acmi.net.au/education/school-program-and-resources/make-stop-motion-animation/?utm_source=chatgpt.com)

### **Source 08 — Investigating How Computational Tools Can Improve the Production Process of Stop-Motion Animation**

**Creator:** Lindsey Elaine Howell / University of Bath, in collaboration with Aardman Animations

**Type:** Doctoral thesis / Academic research (2015)

**Link:** [https://researchportal.bath.ac.uk/en/studentTheses/investigating-how-computational-tools-can-improve-the-production-/](https://researchportal.bath.ac.uk/en/studentTheses/investigating-how-computational-tools-can-improve-the-production-/?utm_source=chatgpt.com)

**Why It Matters:** Investigates how computational tools can improve professional stop-motion production, focusing on rig removal, set shifting, and digital material rendering. This research helped establish that technology can support traditional animation while introducing its own limitations. The discussion of digitally recreating plasticine is especially relevant to Artificial Motion.

### **Source 09 — Kubo and the Two Strings: Steve Emerson – VFX Supervisor – LAIKA**

**Creator:** Vincent Frei / The Art of VFX, interviewing Steve Emerson

**Type:** Professional interview / VFX case study (2016)

**Link:** [https://www.artofvfx.com/kubo-and-the-two-strings-steve-emerson-vfx-supervisor-laika/](https://www.artofvfx.com/kubo-and-the-two-strings-steve-emerson-vfx-supervisor-laika/?utm_source=chatgpt.com)

This helped me understand how digital technology can expand traditional animation without necessarily replacing its handmade qualities. Although the techniques discussed are not generative AI, they provide an important reference for considering where AI belongs in the creative process.

### **Source 11 — How to Make Stop-Motion Animation with AI (GPT Image 2.5 Tutorial)**

**Creator:** PixCirce Team / PixCirce AI

**Type:** Online article / AI animation workflow tutorial (2026)

### **Source 12 — AI Paper Cutout Animation: How We Made a Full Short**

**Creator:** Jordan, Cofounder of Framesail AI (2026)

**Type:** Online article / AI animation workflow and case study

**Link:** https://framesail.com/blog/ai-paper-cutout-animation

**Why It Matters:** This article explores how AI can create paper cutout animation while maintaining consistent textures, layered materials, and character designs across multiple shots.
