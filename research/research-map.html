Artificial Motion / Workspace

Research map

Source 01 — Onion Skinning

Stop Motion Studio / Cateater
Software documentation

Explains how existing onion-skin tools allow animators to compare frames during capture. This provides a useful starting point for understanding what features already exist and how an AI assistant would need to offer something different.

Source 02 — Dragonframe Software Features

Dragonframe
Software overview / technical documentation

Dragonframe includes professional animation tools such as overlays, difference mode, and image review. Studying these features could help establish what technical problems have already been addressed and where beginner-focused AI assistance might offer additional value.

Source 03 — Visual Image Comparison

scikit-image contributors
Technical documentation / coding example

Demonstrates techniques for visually comparing two images, including difference and blended views. These methods could be useful as a technical starting point or baseline when testing AI-assisted frame comparison.

Source 04 — Animation Guides

Stop Motion Studio / Cateater
Software documentation

Explores existing tools for planning movement, positioning characters, and maintaining camera alignment. Initially useful for understanding what FrameZero could offer, these features also provide a foundation for evaluating movement control and consistency in AI-generated animation.

Source 05 — How to Reduce Flicker? What Are Possible Sources of Flicker?

Dragonframe / DZED Systems
Technical documentation / Troubleshooting resource

Identifies common causes of lighting flicker during stop-motion production, including inconsistent exposure, changing light sources, and reflections. This helped establish the importance of visual consistency between frames, an issue that remains relevant when evaluating AI-generated animation.

Source 06 — How to Use Background Subtraction Methods

OpenCV / Domenico Daniele Bloisi
Computer vision documentation / Technical tutorial

Introduces computational methods for identifying differences between an image and its background. Originally relevant to detecting unwanted changes between captured frames, this research also suggests ways to evaluate unintended movement or inconsistencies in AI-generated animation.

Source 07 — Make a Stop-Motion Animation

ACMI (Australian Centre for the Moving Image)
Educational guide / Production tutorial

Breaks down the traditional stop-motion process, including storyboarding, camera setup, lighting, frame rates, and animation techniques. Although introductory, this source helped establish the fundamental production principles that AI-generated stop-motion-style animation would need to reproduce.

Source 08 — Investigating How Computational Tools Can Improve the Production Process of Stop-Motion Animation

Lindsey Elaine Howell / University of Bath, in collaboration with Aardman Animations
Doctoral thesis / Academic research (2015)

Investigates how computational tools can improve professional stop-motion production, focusing on rig removal, set shifting, and digital material rendering. This research helped establish that technology can support traditional animation while introducing its own limitations. The discussion of digitally recreating plasticine is especially relevant to Artificial Motion.

Source 09 — Kubo and the Two Strings: Steve Emerson – VFX Supervisor – LAIKA

Vincent Frei / The Art of VFX, interviewing Steve Emerson
Professional interview / VFX case study (2016)

Explores how LAIKA combines physical stop-motion animation with digital effects and compositing. This helped me understand how digital technology can expand traditional animation without necessarily replacing its handmade qualities. Although the techniques discussed are not generative AI, they provide an important reference for considering where AI belongs in the creative process.

Source 10 — Create Videos in Google Flow

Google
Official software documentation / AI video generation tutorial

Explains how Google Flow generates video using text prompts, reference images, and starting or ending frames. This provides a potential workflow for producing stop-motion-style animation while testing the amount of control AI allows over character movement, scene composition, and visual consistency.

Source 11 — How to Make Stop-Motion Animation with AI (GPT Image 2.5 Tutorial)

PixCirce Team / PixCirce AI
Online article / AI animation workflow tutorial (2026)

Demonstrates an alternative approach to AI animation by generating individual frames through image editing rather than producing an entire video from a single prompt. The workflow emphasizes maintaining consistent characters, environments, and camera positioning between frames. This directly influenced my new project direction by introducing a method that more closely resembles traditional frame-by-frame animation. However, its claims about consistency still need to be tested independently.

Source 12 — AI Paper Cutout Animation: How We Made a Full Short

Jordan, Cofounder of Framesail AI (2026)
Online article / AI animation workflow and case study

This article explores how AI can create paper cutout animation while maintaining consistent textures, layered materials, and character designs across multiple shots. It is relevant to my project because it introduces an alternative to clay and LEGO animation that might be easier for AI to replicate convincingly, while offering techniques for preserving a handmade appearance in AI-generated videos.
